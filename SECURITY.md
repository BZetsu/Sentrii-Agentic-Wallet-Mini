# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Sentrii Open Source Standard, please DO NOT report it publicly. Instead, contact the team directly to arrange a secure disclosure.

## Scope
This repository contains the **public integration standard** and **protocol types**. It does NOT contain the private Sentrii Agent runtime, Vault/Signing internals, or Threat-Analysis logic.

Do not submit PRs that attempt to bypass confirmation requirements or execute arbitrary code. The Sentrii Standard explicitly does not allow hidden runtime powers.
